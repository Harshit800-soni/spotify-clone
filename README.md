# 🎵 Spotify Clone

A simple Spotify Clone built using **HTML, CSS, and JavaScript**.  
This project recreates the basic UI and music player functionality of Spotify.

- 🎶 Simply add your favorite songs to the `songs` folder and play them directly in the music player.

## 🚀 Features

- 🎧 Play/Pause music
- ⏭️ Next & Previous song controls
- 📃 Song playlist display
- 🔊 Music progress bar
- 🎨 Responsive and modern UI
- 💻 Built with pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
